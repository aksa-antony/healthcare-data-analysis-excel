# Healthcare Data Analysis - Excel

## Project Overview
This project analyzes healthcare data using Microsoft Excel. The project involved data cleaning, data transformation, PivotTable analysis, and the creation of an interactive healthcare dashboard.

## Data Cleaning and Transformation
- Handled missing and inconsistent values.
- Standardized healthcare-related categorical data.
- Split customer names into meaningful fields.
- Created Weight Status categories based on BMI.
- Created Diabetes Status categories based on HbA1c levels.
- Created Date of Birth and calculated customer age.
- Formatted healthcare charges as currency.

## Data Analysis
PivotTables and PivotCharts were used to analyze relationships between healthcare factors such as:

- Weight Status and Diabetes Status
- Smoking Status and Cancer History
- State and Hospital Tier
- Age and BMI
- Age and HbA1c
- Age and Healthcare Charges

## Dashboard
An interactive Excel dashboard was created using PivotCharts and slicers to present the healthcare analysis.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
